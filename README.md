# 🏅 Global Olympic Sports Performance Analysis

## 📌 Project Overview

Global Olympic Sports Performance Analysis is a data visualization project developed using Tableau. It aims to make Olympic medal data easier to explore, compare, and understand through interactive visualizations.

The dashboard presents country-level medal performance, compares Gold, Silver, and Bronze medals, examines Summer and Winter Olympic performance, and explores medal trends over time.

## ❗ Problem Statement

Olympic medal data can be difficult to analyze when it is presented only in large tables or raw records. Identifying top-performing countries, comparing medal categories, understanding seasonal differences, and tracking historical performance can require considerable manual effort.

This project addresses the problem by presenting Olympic performance data through clear and interactive Tableau visualizations.

## 🎯 Project Objectives

- Identify leading countries based on the medal measure used in the dashboard.
- Compare Gold, Silver, and Bronze medal performance.
- Explore differences between Summer and Winter Olympic Games.
- Analyze changes in medal performance over time.
- Make Olympic data easier to understand through visual analytics.

## 📊 Dashboard Visualizations

### 1. Top 10 Countries
A horizontal bar chart used to compare leading countries based on the measure displayed in the dashboard.

**Scenario:** Which countries have the highest recorded medal performance?

### 2. Medal Comparison
A visualization comparing Gold, Silver, and Bronze medals.

**Scenario:** How is medal performance distributed across different medal categories?

### 3. Olympic Season Performance
A comparison of Summer and Winter Olympic performance.

**Scenario:** How do medal patterns differ between the two Olympic seasons?

### 4. Olympic Medals Trends Over Time
A line chart showing medal performance across Olympic years.

**Scenario:** How has recorded medal performance changed over time?

### Interactive Country Filter
The dashboard includes a country filter to support focused analysis of a selected country, where applicable.
